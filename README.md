# Colin Vitols

I build full-stack applications that turn data into useful dashboards, explainable models, and practical workflows. My projects span sustainable infrastructure, clinical trial simulations, and applied AI for cybersecurity.

I enjoy connecting Python backends with React interfaces, then working through the details that make a prototype more useful: persistent data, clear visualizations, reliable APIs, and traceable decisions.

## Featured projects

### [GreenGrid](https://github.com/vitolscolin/GreenGrid)

A municipal infrastructure control platform prototype for exploring workload placement, energy use, carbon impact, and cost.

- Built with **FastAPI, Next.js, TypeScript, SQLAlchemy, and PostgreSQL**, with SQLite support for local development.
- Includes recommendation review, migration simulations, scheduled automation, and persistent audit history.
- Recent work focuses on recommendation lifecycle reliability, dashboard resilience, and chart data consistency.

### [TrialTwin AI](https://github.com/vitolscolin/RevolutionaryCreepers)

A team hackathon project that uses synthetic clinical trial participants to compare adherence scenarios and visualize how projected outcomes diverge.

- Combines **React, FastAPI, pandas, scikit-learn, and SQLite** with interpretable risk models and interactive charts.
- My contributions include adding a persistent local trial database.
- An educational simulation built with synthetic data, not a clinical tool.

### [Applied AI for Cybersecurity](https://github.com/vitolscolin/IT7075-Applied-AI-for-Cybersecurity)

My repository for University of Cincinnati's IT7075C coursework, with hands-on Python and Jupyter notebook work.

- Recent work includes environment setup, verification, and configuration updates.
- The course explores local and cloud LLMs, retrieval-augmented generation, LangChain, LangGraph, MCP, and defensive security workflows.
